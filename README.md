# Blogging Platform 🚀

Una plataforma de blogs moderna construida con Spring Boot y React.

## Características principales ✨

- Creación y gestión de posts de blog
- Autenticación de usuarios
- Interfaz responsive y amigable
- API RESTful 
- Sistema de comentarios

## Stack tecnológico 💻

### Backend (Spring Boot)
- **Lenguaje**: Java 11+
- **Framework**: Spring Boot 3.4.5+
- **Base de datos**: PostgreSQL
- **Seguridad**: Spring Security
- **API Docs**: Swagger

### Frontend (React)
- **Lenguaje**: TypeScript
- **Framework**: React 19+
- **Estado**: zustand
- **Estilos**: Tailwind
- **Routing**: React Router DOM

## Requisitos previos 📋

- JDK 11+
- Node.js 16+
- Maven/Gradle (según configuración)

## Instalación ⚙️

### Backend
```bash
cd backend
mvn spring-boot:run
# o
./gradlew bootRun
```
